# CineHub


Sobre:

O CineHub é um projeto desenvolvido com HTML, CSS e Javascript com o objetivo de permitir que o usuário organize os filmes que já assistiu em um único lugar. A aplicação possibilita cadastrar filmes, dar uma nota de 1 a 5, informar o ano de lançamento do filme, selecionar o gênero e adicionar uma resenha opcional sobre a experiência ao assistir.

Além de funcionar como um catálogo pessoal, o projeto também tem um sistema de recomendações, onde o usuário escolhe um gênero e são dadas 5 sugestões de filmes relacionadas ao genero escolhido, ajudando na descoberta de novos títulos.


Objetivo:

O principal objetivo do projeto é oferecer uma forma simples e prática de registrar filmes assistidos e facilitar a organização dessas informações. Ao mesmo tempo, o sistema incentiva o usuário a conhecer novos filmes por meio das recomendações disponíveis.


Como funciona:

O usuário pode cadastrar um filme informando o nome, ano de lançamento, gênero, nota e uma resenha opcional.
Após o cadastro, todos os filmes adicionados ficam visíveis na página, permitindo ver a lista sempre que desejar.
Também é possível selecionar um gênero para receber recomendações de filmes previamente cadastradas no sistema.


Tecnologias utilizadas:

O projeto foi desenvolvido utilizando o HTML para a estrutura da página, CSS para a estilização do site e Javascript para implementar toda a lógica de funcionamento, como o cadastro de filmes, a exibição da lista e o sistema de recomendações.


Considerações:

Este projeto foi desenvolvido com fins de estudo para praticar conceitos de crud e desenvolvimento web, criação de funções em JavaScript, armazenamento de dados em arrays e interação com formulários. Durante o desenvolvimento foram aplicados conceitos básicos de programação, como estruturas de repetição, objetos, funções e filtros de dados, permitindo colocar em prática os conhecimentos adquiridos em sala de aula.
